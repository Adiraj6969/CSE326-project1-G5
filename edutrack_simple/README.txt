EDUTRACK - SIMPLE ASSIGNMENT SUBMISSION PROJECT

FILES
1. index.html  - Student and assignment form.
2. style.css   - Colours and page design.
3. success.html - Confirmation page after the form is submitted.

HOW TO OPEN
1. Extract this ZIP file.
2. Keep all three files in the same folder.
3. Double-click index.html to open the project in a browser.
4. Fill in the form and press Submit Assignment.

WHAT THIS PROJECT DOES
- Collects basic student details.
- Lets a student choose a course, subject and teacher.
- Collects assignment name, date, time and a file selection.
- Uses a small JavaScript redirect to open a success page after submission.

IMPORTANT LIMITATION
This is a beginner front-end demonstration made with HTML and CSS.
The success page demonstrates the submission flow, but the project does not
upload files or save form details. Real storage requires a backend and database.
